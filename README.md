Project Description : High School Course Selection System is a comprehensive online platform designed to centralize academic administration and virtual learning for students and faculty. It replaces manual, paper based registration with a digital environment that supports the entire student lecturer lifecycle  
   Objective: To streamline course enrollment while providing integrated tools for remote learning and real time communication  
   Key Features: - Booking Session  
                 - Online Meeting  
                 - Study Material Resources Management  
                 - Interaction Hub  
                 - Assessment Module  
  
Overview of Your SDLC Work : This project was developed using the Agile Scrum methodology over a 4-week period. The process focused on iterative development, allowing for continuous feedback and refinement of the system’s core features.  
     - Phase 1: Initiation & Planning (Week 1)  
     - Phase 2: Sprint 1 – Design & Prototyping (Week 2)  
     - Phase 3: Sprint 2 – Build & Testing (Week 3)  
     - Phase 4: Finalization & Delivery (Week 4)  
     
     Using tools:
     - Trello for Kanban
     - Figma for UI sketches
